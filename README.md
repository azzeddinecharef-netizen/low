# مقرر قانون العمل

مقرر تعليمي عربي يضم المحاضرات العشر والسيلابس كاملين بصور صفحات المصدر الأصلية، مع اختبار مستقل لكل محاضرة.

## الصفحة التعليمية

[افتح المقرر المنشور](https://azzeddinecharef-netizen.github.io/low/)

## الاختبارات

لكل محاضرة 20 عبارة صح أو خطأ. الأسئلة مباشرة من موضوعات المحاضرات، ولكل إجابة خاطئة تصويب يشرح العبارة الصحيحة. تُحسب الدرجة من 20 بعد الإجابة عن جميع البنود.

## تنزيل الحزمة

[تحميل حزمة الموقع متعددة الملفات — الإصدار v2](https://github.com/azzeddinecharef-netizen/low/raw/refs/heads/main/qanun-al-amal-ar-v2.zip)

فك ضغط الحزمة ثم افتح `index.html` بمتصفح حديث. ينشر GitHub Actions صفحات الموقع بعد فك الحزمة تلقائيًا عند تحديث الفرع الرئيسي.

تتضمن صفحات المحاضرات صور المصدر الأصلي وملفات PDF. مخطط التأليف بأسلوب Opale موجود داخل الحزمة؛ الموقع وملف HTML المستقل ليسا مشروع Opale قابلًا للاستيراد.
