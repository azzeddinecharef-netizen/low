# مقرر قانون العمل

مقرر تعليمي باللغة العربية يضم المحاضرات العشر والسيلابس كاملين بصور صفحات المصدر الأصلية، مع اختبار مستقل لكل محاضرة. أُعدّ المقرر باسم الدكتور طهير عبد الرحيم، ويظهر على واجهته الانتماء إلى جامعة عين تموشنت بلحاج بوشعيب.

تعرض الواجهة هوية الجامعة والوزارة واسم الأستاذ في شريط علوي ثابت، ثم عنوان المقرر والكلية والسنة الرابعة، ثم روابط الرئيسية والسيلابس والمحاضرات.

## الصفحة التعليمية

[افتح المقرر المنشور](https://azzeddinecharef-netizen.github.io/low/)

## الاختبارات

لكل محاضرة 20 عبارة صح أو خطأ. بعد الإجابة عن جميع البنود تظهر الدرجة من 20، مع توضيح صحة العبارة أو خطئها وتصويب العبارة الخاطئة.

## تنزيل الحزمة

[تحميل حزمة الموقع متعددة الملفات — الإصدار v7](https://github.com/azzeddinecharef-netizen/low/raw/refs/heads/main/qanun-al-amal-ar-v7.zip)

فك ضغط الحزمة ثم افتح `index.html` بمتصفح حديث. ينشر GitHub Actions صفحات الموقع بعد فك الحزمة تلقائيًا عند تحديث الفرع الرئيسي.

تتضمن الحزمة صور صفحات المحاضرات وملفات PDF الأصلية. مخطط التأليف بأسلوب Opale موجود داخل الحزمة؛ الموقع وملف HTML المستقل ليسا مشروع Opale قابلًا للاستيراد.
