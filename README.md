# مقرر قانون العمل


مقرر تعليمي باللغة العربية يضم المحاضرات العشر والسيلابس كاملين بصور صفحات المصدر الأصلية، مع اختبار مستقل لكل محاضرة. أُعدّ المقرر باسم الدكتور طهير عبد الرحيم، ويظهر على واجهته الانتماء إلى جامعة عين تموشنت بلحاج بوشعيب.


تعرض الواجهة هوية الجامعة والوزارة واسم الأستاذ في شريط علوي ثابت، ثم عنوان المقرر والكلية والسنة الرابعة، ثم روابط الرئيسية والسيلابس والمحاضرات.

## الاختبارات


لكل محاضرة 20 عبارة صح أو خطأ. زر «عرض المحاضرة» يفتح المحتوى الأصلي، وزر «اختبر نفسي» يفتح الاختبار. بعد الإجابة عن البنود العشرين تظهر الدرجة من 20، مع توضيح صحة العبارة أو خطئها وتصويب العبارة الخاطئة.
