# مقرر قانون العمل

مقرر تفاعلي باللغة العربية، يضم المحاضرات العشر كاملة بصور صفحات المصدر واختبارًا مستقلًا من 20 سؤالًا لكل محاضرة.

## الصفحة التعليمية

https://azzeddinecharef-netizen.github.io/low/

## محتويات المستودع

- `qanun-al-amal-ar.zip`: حزمة الموقع متعددة الملفات كاملة، بما فيها صفحات المحاضرات والاختبارات وملفات المصدر.
- ينشر GitHub Actions نسخة الموقع بعد فك الحزمة تلقائيًا عند تحديث الفرع `main`.

للتشغيل محليًا، نزّل الحزمة وفك ضغطها ثم افتح `index.html`.
